# Additional free LLM API platforms for `freeai` presets (beyond OpenRouter, Groq, Cerebras, Gemini, Mistral) — state as of 2026-11-06

## 1. Which platforms have a genuinely free tier (permanent vs one-time trial), and what does sign-up require?

### Takeaway
Of the ~25 candidates, only a handful offer a renewable (daily/hourly/monthly-resetting) free quota on an OpenAI-compatible endpoint in Nov 2026: Cloudflare Workers AI, Z.ai GLM-Flash models, Kilo Gateway, Requesty, NVIDIA build.nvidia.com, SambaNova, Cohere (trial key), OVHcloud (anonymous only), Nous Portal, AionLabs, AMD Radeon Token Factory (China), Vercel AI Gateway (payment method required). Several former favorites are gone: GitHub Models was retired 2026-07-30, Hugging Face no longer gives free users credits, Together AI has no free trial, Kluster.ai ended inference in 2025, Chutes is pay-as-you-go only. Note also that the existing `freeai` Cerebras preset is now a card-gated $5/30-day trial.

#### Source-quality note and conventions (read first)
- Conventions: "probed 2026-11-06" = an unauthenticated read-only `GET` this researcher ran against the provider's public endpoint on 2026-11-06 (UTC); it shows the endpoint exists and what it lists, not free-tier quotas. "(aggregator)" = number comes from a community list, not the provider. "(UNVERIFIED)" = single secondary source or conflicting sources. `freeai` constructor referenced: `Provider(name, base_url, api_key=..., models=[...], rpm=..., rpd=...)`.
- The suggested curated list `cheahjs/free-llm-api-resources` returned HTTP 404 from the GitHub API on 2026-11-06 and is no longer among `cheahjs`'s public repos (the user account itself resolves) — [GitHub API repo endpoint, probed 2026-11-06](https://api.github.com/repos/cheahjs/free-llm-api-resources); [cheahjs repo list](https://api.github.com/users/cheahjs/repos). Its content was only available as an undated Exa cache — [cheahjs README (cached)](https://github.com/cheahjs/free-llm-api-resources/). That cache is demonstrably stale in places (HF "$0.10/month" vs official "Free Users: None"; SambaNova "$5 trial" vs official Free Tier table), so it is used only where nothing better exists.
- Two actively maintained, dated lists were used instead: `CYBIRD-D/FREE-LLM-API-Provider` ("Last reviewed: 2026-11-02", last commit 2026-11-02, includes CN platforms) — [CYBIRD-D list](https://github.com/CYBIRD-D/FREE-LLM-API-Provider); and `surendranb/free-inference` ("2026-11-05 · 41 providers · 153 free models", last commit 2026-11-05) — [surendranb/free-inference](https://github.com/surendranb/free-inference).

### Inferences
- For a failover SDK whose value is "keeps working for free indefinitely", only quotas that reset (daily/hourly/monthly) matter. Trial-credit providers (Alibaba, Scaleway, Fireworks, Nebius, Hyperbolic, DeepInfra, Cerebras now) burn out once and then either stop or bill the user; Alibaba in particular auto-bills unless "Free Quota Only" is on, which is a footgun for an SDK that auto-rotates.
- "No credit card" filter: Cloudflare, Z.ai, Kilo, Requesty, NVIDIA, SambaNova, Cohere, OVH-anonymous, Nous pass. Vercel AI Gateway and Cerebras fail (payment method required). OVH authenticated fails.
- The existing Cerebras preset should probably be relabeled as "trial/credit" or demoted in default rotation (out of this note's scope but directly affects `freeai`).

### Gaps
- Whether a Cloudflare account on the Workers Free plan needs a card to create an API token was not checked on a primary page (aggregator says no).
- Z.ai sign-up requirements (phone verification? region restrictions?) were not found.
- AMD Token Factory sign-up requirements (Chinese phone/real-name?) and the global vs China-site distinction were not verified.
- NVIDIA: whether the 2026 model is "credits + 40 RPM" or "rate-limited free endpoints only" could not be settled from primary sources; the credit amount (1,000) is only in forum titles.
- Nous Portal free-plan limits are not on a primary page fetched here.

## 2. Base URL, auth header, `GET /models`, and how to identify free models programmatically

### Takeaway
Every shortlisted platform uses `Authorization: Bearer <key>` against an OpenAI-style `/chat/completions`. Kilo, Requesty, Nous, OVH, NVIDIA, SambaNova and Vercel expose a public `GET /models` (no auth needed in probes). Programmatic free detection is clean on Kilo (`isFree`), Requesty (zero prices) and Nous (`:free`), but on NVIDIA, Cloudflare, Z.ai and Vercel the free set must be hard-coded from docs.

### Cited Findings
- **Cloudflare**: base `https://api.cloudflare.com/client/v4/accounts/${CLOUDFLARE_ACCOUNT_ID}/ai/v1`; `--header "Authorization: Bearer {api_token}"`; `POST …/ai/v1/chat/completions` with model like `@cf/meta/llama-3.1-8b-instruct`; Responses API only for GPT-OSS; optional `options.rejectIfBusy` in the request body "makes the request fail instead of waiting in a capacity queue"; page updated Sep 18, 2026 — [Cloudflare OpenAI-compatible endpoints](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/).

### Inferences
Suggested preset sketches (model lists are a snapshot; prefer dynamic discovery where the platform supports it):
- `Provider("cloudflare", f"https://api.cloudflare.com/client/v4/accounts/{CF_ACCOUNT_ID}/ai/v1", api_key=CF_API_TOKEN, models=["@cf/openai/gpt-oss-120b", "@cf/meta/llama-3.3-70b-instruct-fp8-fast", "@cf/qwen/qwen3-30b-a3b-fp8", "@cf/google/gemma-4-26b-a4b-it", "@cf/zai-org/glm-4.7-flash"], rpm=300)` (the last two IDs come from the cheahjs cache, not the official pricing page) — base URL needs a second credential (account ID), so the preset needs a template parameter. Exclude the eight paid-billing models listed by Cloudflare.
- `Provider("zai", "https://api.z.ai/api/paas/v4", api_key=ZAI_KEY, models=["glm-4.7-flash", "glm-4.5-flash", "glm-4.6v-flash"], rpm=<low, e.g. 10>)` — model-ID casing not verified (pricing page uses `GLM-4.7-Flash`).

## 3. Free limits (RPM/RPD/TPM/TPD/neurons/credits), scope, and the shape of 429 / quota-exhausted errors

### Takeaway
Error shapes are well documented for Cloudflare (code 3036 = daily neurons exhausted, 3040 = capacity), Vercel, Z.ai (several distinct business codes all on HTTP 429, including "insufficient balance") and AMD (two nested body shapes plus `Retry-After`). SambaNova documents headers but not the body. The key SDK lesson: several providers use HTTP 429 for both "slow down" and "you're out for today/out of balance", so `freeai` should parse body codes to decide between short backoff and long provider cooldown.

### Cited Findings

- **Cloudflare errors**: "Account limited | 3036 | 429 | You have used up your daily free allocation of 10,000 neurons"; "Out of capacity | 3040 | 429 | No more data centers to forward the request to" — [Cloudflare Workers AI errors](https://developers.cloudflare.com/workers-ai/platform/errors/).

### Inferences
- `freeai` should classify by body code, not only status:
  - Long cooldown (until reset): Cloudflare `3036` (until 00:00 UTC), Z.ai `1308`/`1310` (until `next_flush_time`), Z.ai `1113` (treat as permanently unavailable for that key/model), AMD "Daily usage limit exceeded" (honor `Retry-After`), Vercel `402 quota_for_entity_exceeded` and `403 customer_verification_required` (disable provider).
  - Short backoff / rotate: Cloudflare `3040`, Z.ai `1302`/`1305`, AMD concurrency codes (`Retry-After: 1`), SambaNova/OVH/Vercel generic 429.
  - Not a failover trigger (or a configurable one): Z.ai `1301` (HTTP 400 content filter) — rotating to another provider might be desired, but it is not a quota event.
- AMD's admission errors are nested under `detail`, so a parser that only reads `error.code` will miss them.
- Cloudflare's daily neuron budget is small for 70B-class models (~78.5K tokens/day by aggregator math) but large for small MoE models (~500K tokens/day), so presets should favor `qwen3-30b-a3b-fp8`, `gemma-4-26b-a4b-it`, `glm-4.7-flash`, `gpt-oss-20b/120b` over Llama 3.3 70B.
- Z.ai's reported 1-concurrency limit means a parallel caller using one key will see 429s even at low RPM; the SDK is sync, so single-threaded use is fine but multi-thread users need a per-provider semaphore.

### Gaps
- No documented 429 body for SambaNova, Cohere, NVIDIA, Kilo, Requesty, Nous, or OVH was found; only status codes/headers.
- Kilo authenticated free-model limits and Requesty per-minute limits are not published on pages fetched.
- Whether Cloudflare's OpenAI-compatible endpoint returns the 3036/3040 codes in the same envelope as the native REST API was not verified.

## 5. Terms: training on prompts, commercial use, regional restrictions, multi-account / limit-evasion rules

### Takeaway
Free tiers that route to NVIDIA trial endpoints log prompts for product improvement; Kilo flags every free model as `mayTrainOnYourPrompts`. Cloudflare and OVH explicitly do not train on customer prompts; Z.ai's policy is ambiguous and excludes sanctioned regions. Cohere trial keys are commonly described as non-production/non-commercial. Alibaba explicitly blocks re-registration for more quota, and NVIDIA says there is "no official way to circumvent" the rate limit. An SDK that rotates across providers is fine; rotating across multiple accounts of the same provider is the risky pattern.

## 7. Excluded / gray platforms and the prioritized shortlist

### Takeaway
Recommended additions, in order: (1) Cloudflare Workers AI, (2) Z.ai GLM-Flash, (3) Kilo Gateway, (4) NVIDIA build.nvidia.com, (5) Requesty; then SambaNova and Cohere as low-volume last-resort tiers, OVH anonymous as an optional keyless fallback. Exclude reverse-engineered/proxy services (g4f-style, and LLM7/Pollinations until their licensing basis is shown).

### Cited Findings
- cheahjs list policy: "This list explicitly excludes any services that are not legitimate (eg reverse engineers an existing chatbot)"; "Please don't abuse these services, else we might lose them." — [cheahjs README (cached)](https://github.com/cheahjs/free-llm-api-resources/).
- **LLM7**: `GET https://api.llm7.io/v1/models` lists 70 models in `turbo`/`pro` tiers with per-token pricing (e.g., `DeepSeek-V4-Flash-0731` $0.02/$0.04 per M) and proxies of proprietary models such as `anthropic/claude-opus-4-8` and `anthropic/claude-sonnet-5` (probed 2026-11-06) — [LLM7 models endpoint](https://api.llm7.io/v1/models). Third-party directories describe it as "a shared community proxy, where rate limits and availability are not guaranteed" with conflicting limits (30 RPM no signup / 120 RPM with token vs 60/min, 250/hour, 100K tokens/24h) — [fremodel LLM7 page](https://fremodel.pages.dev/providers/llm7-io); [free-llm.com LLM7](https://free-llm.com/provider/llm7-io). No official terms were found.
- **Pollinations**: `GET https://gen.pollinations.ai/v1/models` lists 257 text models; non-`paid_only` entries include `openai/gpt-6.1-sol`, `openai/gpt-6-sol`, `x-ai/grok-4.6`, `moonshotai/kimi-k3`, plus a large set of user-submitted `community/*` models (e.g., `community/AkshayCoder48/claude-fable-5`) (probed 2026-11-06) — [Pollinations models endpoint](https://gen.pollinations.ai/v1/models). Usage billed in "Pollen" ($1 ≈ 1 Pollen), free Pollen via quests; older sources claim keyless free access with ~20 RPM (UNVERIFIED) — [tooldirectory Pollinations](https://tooldirectory.ai/tools/pollinations); [pollinations-client on PyPI](https://pypi.org/project/pollinations-client/).
- Dead/no free tier: GitHub Models — [GitHub changelog](https://github.blog/changelog/2026-07-30-github-models-is-now-retired/); HF free users — [HF pricing](https://huggingface.co/docs/inference-providers/pricing); Together — [Together support](https://support.together.ai/articles/1862638756-changes-to-free-tier-and-billing-july-2025); Kluster.ai — [kluster.ai blog](https://kluster.ai/blog/end-of-life-for-inference-fine-tuning-and-dedicated-deployments); Chutes — [Chutes pricing](https://chutes.ai/pricing).

### Inferences
**Exclusions and why**
- g4f-style reverse-engineered "free GPT" services: they relay unauthenticated or scraped access to commercial chatbots, which providers' terms do not permit; shipping them as SDK presets would expose users to account bans, legal risk, and unstable endpoints, and would conflict with the curated-list norm quoted above. (Inference; OpenAI's terms page could not be fetched — 403 — so no direct ToS quote is included.)
- LLM7 and Pollinations: both expose frontier proprietary models (Claude, GPT-6.x, Grok) through a shared proxy or user-submitted "community" routes with no evidence of a licensed reseller arrangement; also both have moved toward paid/credit models. Classify as "gray — not recommended as presets" until official terms/licensing are documented.
- Trial-credit-only providers (Alibaba, Scaleway, Fireworks, Nebius, Hyperbolic, DeepInfra, Novita, AI21, Upstage, Baseten, Modal, Inference.net): offer as optional "bring your own credits" presets at most; Alibaba especially should not be auto-enabled because it auto-bills after the free quota unless "Free Quota Only" is set.
- Vercel AI Gateway: requires a payment method, only a small, unpublished-limit free subset, and the free credit vanishes permanently once any credits are purchased — low value for a free-failover SDK.
- AionLabs (20K tokens/day), ModelScope/SiliconFlow (Chinese real-name verification), AMD Token Factory (China site, ~1 pt/day typical per aggregator) — skip for a general global preset set; AMD could be an opt-in preset for users in China.

**Prioritized shortlist (top 5)**
1. **Cloudflare Workers AI** — permanent, documented, daily-resetting 10K neurons; 300 RPM; own infrastructure (true capacity diversity); excellent error documentation (3036 vs 3040) for precise cooldown logic; official "No training" and zero-retention commitment; long-lived program. Caveats: base URL needs account ID; budget is small for 70B models; eight frontier models are billing-gated.
2. **Z.ai GLM-4.7-Flash / GLM-4.5-Flash / GLM-4.6V-Flash** — listed as fully "Free" on the official pricing page (not a promo label), includes a vision model, well-documented business error codes. Caveats: reported 1-concurrency and peak-hour throttling; privacy policy ambiguous on prompt training; terms exclude sanctioned regions; `1113` insufficient-balance arrives as 429.
3. **Kilo AI Gateway** — renewable free models with machine-readable `isFree` + `mayTrainOnYourPrompts`, unauthenticated `/models`, works even anonymously (200 req/h/IP), 11 free models incl. 1M-context Nemotron 3.5. Caveats: free list rotates; all free models may train on prompts; overlaps with NVIDIA/OpenRouter backends.
4. **NVIDIA build.nvidia.com** — largest free catalog of strong open models (Nemotron 3 Ultra/Super, GPT-OSS, GLM-5.3-Flash, Kimi K2.6, DeepSeek V4.1 Flash, Gemma 4) at ~40 RPM. Caveats: trial terms (prompts logged), "Free Endpoint" status not machine-readable, possible credit-based cap, limits vary with traffic.
5. **Requesty** — $0 plan, no card, 200 requests/day, zero-price models detectable from `/models`. Caveats: small daily cap; mostly NVIDIA-hosted Nemotron models (backend overlap); training terms unknown.
- Runners-up / last-resort tier: **SambaNova** (strong models but only 20 RPD per model), **Cohere** (1,000 calls/month, distinct Command A family, non-production key), **OVH anonymous** (keyless, 2 RPM per model, EU, no training), **Nous Portal** (4 `:free` models, limits unverified).

### Gaps
- No direct quote from OpenAI/Anthropic terms was retrieved for the g4f exclusion rationale (OpenAI terms page returned 403).
- No evidence either way on whether LLM7 or Pollinations have upstream licensing agreements.
- Real-world 2026 reliability for Kilo/Requesty free routes (forum/Reddit reports) was not researched within the tool budget.
